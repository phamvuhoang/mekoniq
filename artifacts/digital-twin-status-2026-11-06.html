REPORT_WORK="$(mktemp -d "${TMPDIR:-/tmp}/mekoniq-twin.XXXXXX")"

01 · Chuẩn bị ROS workspace trên Linux
# Từ source checkout đã pin a89a077, trên Linux đã provision ROS/Gazebo/colcon:
. /opt/ros/jazzy/setup.bash
colcon build --base-paths robotics/description robotics/navigation robotics/simulation   --packages-select mekoniq_description mekoniq_navigation mekoniq_simulation
. install/setup.bash
python3 -m venv --system-site-packages .venv-sil
. .venv-sil/bin/activate
python -m pip install -r robotics/simulation/requirements-dev.txt -e robotics/agent
nvm use
pnpm install --frozen-lockfile
node scripts/lab-sil.mjs doctor --backend gazebo_nav2 --json

Ubuntu 24.04 / ROS 2 Jazzy / Gazebo Harmonic là baseline trong image.lock.json. Các ROS packages theo robotics/simulation/Dockerfile phải có trước. Đây là hướng dẫn validation chưa chạy trên host Linux của lượt này; doctor xanh là prerequisite, chưa phải SIL pass.

02 · Bắt đầu từ AMR-only, rồi verify evidence
# Cùng Linux shell đã source ROS, workspace và venv:
node scripts/lab-sil.mjs run --scenario FD01 --seed 23 --repeat 3   --backend-set simulation-default --out /tmp/mekoniq-sil-fd01-a89a077
node scripts/lab-sil.mjs verify --input /tmp/mekoniq-sil-fd01-a89a077

Sau FD01, lần lượt mở FD02, FD03, FD04 và FD07 với thư mục output riêng. Required backends theo scenario; không tự thay unavailable bằng mock.

03 · Campaign chỉ sau khi bổ sung integration còn thiếu
# Chưa phải đường chạy hoàn chỉnh ở snapshot hiện tại:

Chỉ SIM · hardware disabled

01 · Doctor và controller smoke trên host Linux đã provision
# Từ source checkout đã pin, python3 phải import được linuxcnc:
node scripts/lab-sil.mjs doctor --backend linuxcnc_sim --json
cd integrations/arm-controller
bash scripts/smoke-sim.sh --profile configs/sim/puma560/mekoniq.ini   --evidence-dir /tmp/mekoniq-arm-terminal-a89a077
bash scripts/smoke-sim.sh --profile configs/sim/puma560/mekoniq.ini   --evidence-dir /tmp/mekoniq-arm-gui-a89a077 --gui

Dependency lock là candidate: Debian 12 amd64, LinuxCNC/PyQt5/QScintilla; cần chốt phiên bản và image/package hashes từ host sạch. Không áp dụng apt install như thể lock đã qualified. GUI cần desktop; smoke dùng virtual HAL, không nối drive thật.

02 · Export tại signing station được provision
# Từ source sạch. Các biến phải trỏ đến cấu hình signing station thật:
: "${ARM_EXPORT_DIR:?Thiet lap thu muc output moi}"
: "${ARM_RELEASE_KEY_FILE:?Thiet lap duong dan private key cua signing station}"
: "${ARM_RELEASE_KEY_ID:?Thiet lap key id da provision}"
node scripts/export-arm-controller.mjs "$ARM_EXPORT_DIR"   --signing-key "$ARM_RELEASE_KEY_FILE" --key-id "$ARM_RELEASE_KEY_ID"

Không đưa private key vào repo/artifact. --allow-unsigned chỉ tạo development artifact bị installer từ chối. Repo trust policy có 0 key, revision 0; host phải được provision policy có active key và positive policyRevision.

03 · First install từ provisioning package tin cậy
# Trên Linux SIM IPC, tài khoản quản trị đã provision identity/group/policy:
: "${ARM_PROVISIONING_DIR:?Thu muc provisioning package da xac thuc}"
: "${ARM_ARTIFACT_DIR:?Thu muc signed artifact da chuyen den IPC}"
: "${ARM_TRUST_POLICY:?Duong dan trust policy do provisioning cap}"
bash "$ARM_PROVISIONING_DIR/scripts/install-sim.sh"   --prefix /opt/mekoniq-arm-sim   --artifact "$ARM_ARTIFACT_DIR" --trust-policy "$ARM_TRUST_POLICY"
bash /opt/mekoniq-arm-sim/current/scripts/verify-install.sh   --prefix /opt/mekoniq-arm-sim

Installer/verifier phải đến từ trusted provisioning, không chạy từ chính artifact đang kiểm. Provision service user mekoniq-arm; group mekoniq-lab và mekoniq-arm-operators tách biệt. Chỉ service thuộc cả hai; client không dùng service UID.

04 · Bật bridge sau khi controller & identity sẵn sàng
# Chạy bằng tài khoản provisioning có quyền quản trị, trên SIM IPC:
cp /opt/mekoniq-arm-sim/current/packaging/systemd/mekoniq-arm-bridge.service   /etc/systemd/system/mekoniq-arm-bridge.service
systemctl daemon-reload
systemctl enable --now mekoniq-arm-bridge.service
systemctl status mekoniq-arm-bridge.service --no-pager
journalctl -u mekoniq-arm-bridge.service -n 80 --no-pager

Bridge không tự khởi động LinuxCNC. Phải có controller SIM chạy bằng host procedure đã xác minh và python3 có jsonschema/referencing + native module. Unit dùng prefix /opt/mekoniq-arm-sim; đổi prefix phải sửa unit tương ứng. Test thực tế quyền hai socket sau mỗi restart trước cấp client access.

05 · Cập nhật từ installer đã cài
# Update signed artifact; dùng biến ARM_ARTIFACT_DIR đã xác định:
bash /opt/mekoniq-arm-sim/current/scripts/install-sim.sh   --prefix /opt/mekoniq-arm-sim --artifact "$ARM_ARTIFACT_DIR"
bash /opt/mekoniq-arm-sim/current/scripts/verify-install.sh   --prefix /opt/mekoniq-arm-sim

Điều phối dừng/chạy service theo maintenance procedure của host; installer đổi current không chứng minh process đã nạp revision mới. Rollback yêu cầu artifact còn trusted và calibration schema tương thích; không rollback trust policy revision.

06 · Rollback riêng khi cần khôi phục
# Chỉ chạy khi cần quay lại last-known-good; không chạy sau update bình thường:
bash /opt/mekoniq-arm-sim/current/scripts/install-sim.sh   --prefix /opt/mekoniq-arm-sim --rollback
bash /opt/mekoniq-arm-sim/current/scripts/verify-install.sh   --prefix /opt/mekoniq-arm-sim

Kiểm last-known-good còn trusted và calibration schema tương thích. Sau rollback, điều phối restart/health-check theo maintenance procedure; giữ journal và policyRevision đã chấp nhận.

Kiểm sau deploy

Verify signature/files; controller native ready; terminal + GUI smoke; allow/deny đúng hai socket qua restart; timeout/lease/reconcile; install/rollback và preservation của journal/calibration. Kiểm này chưa chạy trên host hiện tại. Repo không có lệnh generic enable hardware/live.

Checklist xử lý lỗi thường gặp khi deploy mock
  • RUNTIME_NOT_INSTALLED: import trusted artifact trước; preview UI không có runtime.
  • DIRTY_SOURCE_ARTIFACT / hash mismatch: export từ revision sạch và import lại; không bỏ qua integrity check.
  • PORT_IN_USE: kiểm tiến trình đang giữ 4175/4176; không tự kill tiến trình hoặc robot đang vận hành.
  • BACKEND_UNAVAILABLE: xem prerequisite/capability; không chuyển sang mock rồi giữ nhãn SIL.
  • Trust policy thiếu/expired/revoked: dùng trusted provisioning recovery; không chỉnh manifest hoặc hạ policyRevision.
