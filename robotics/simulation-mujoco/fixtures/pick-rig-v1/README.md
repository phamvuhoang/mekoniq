# Pick rig (R4.4)

Software-only, `accepted:false`, `not_calibrated`. Derived from `coffee-delivery-cell-v1` by `scripts/generate-pick-rig-fixture.mjs`: every model, physics, program, load and project file keeps the cell's bytes. Only `handoff-policy.json` differs (the birth offset limit is 0.03 m instead of 0.005 m) and so the scene digest. `rig-policy.json` also declares the rig's grasp work region (±0.045 m). The rig is a campaign-only scenario of the Source; the browser cannot select it.
