# Serve tray fixture v1

Generate with `node scripts/generate-tray-fixture.mjs [out-dir]`. Three free cups (cup-1..3, 0.32 kg, r 0.04 m) on `amr-1/tray-1`, in two friction variants. The AMR, project, components, world and the nominal drive-contact profile are byte for byte those of `serve-payload-v1`. Friction is one input that lowers the cups and the tray contact together (`drive-contact-tray-low-v1`), because the engine takes the larger friction of the two faces; `feasibility.json` records the geometry and the effective pair friction, and `robotics/simulation-mujoco/tests/test_tray.py` compiles each layout and reads the pair friction back from the model. `tray-policy-v1.json` holds the experiment thresholds and the oracle tolerances (assumed); `actor-proxy-v1.json` declares the box that stands for a person. Everything is `not_calibrated`; nothing here enables a runtime backend.
