# W01-T01 — native atomic journal

Status: implemented; file SQLite exercised in JVM native SQLite and one Android API33 emulator. Two-device/physical acceptance is not claimed.

The Kotlin bridge validates typed batches, scope, persisted authority/policy, aggregate CAS, expected read versions and the authority scope revision (including phantom resource races). WAL/FULL SQLite commits mutations, producer counter, canonical signed journal, audit, receipt, events and outbox together. Same operation with changed type/actor/epoch/version/payload conflicts. Native signing happens before COMMIT; signing or storage failure rolls back. Peer commands persist an intent before TLS transmission; a durable venue receipt completes the intent, while a lost response retains it.

## Limits

Native storage is provisioned for one venue; foreign-scope authority provisioning is rejected. Unsigned `DurableStore.provision/seed` are denied on Android. Full export/restore uses authenticated native SAF methods, not the generic desktop raw-store methods. Device power-loss, Android storage exhaustion and kill-at-COMMIT/ACK windows still require the two-device/physical lab.
