## Durable evidence and regression boundaries

The journal reader copies the bounded database and any WAL/SHM to a private scratch directory. It verifies payload hashes, ES256 signatures, producer identity, contiguous sequence and run scope, then reconstructs fulfillment, mission, parked-robot and coffee-job states. Checkpoint startup/cancel/pause/confirmation/attention flags supply runner-local facts. The verifier compares the complete report outcome, attention and business events before any experiment oracle. The signing key in the retained lab recording provides local record consistency. An independently authenticated artifact inventory is needed for protection against replacement of the entire recording and its keys.

The mobile reader binds physics and navigation to the same scene, boot and run, then replays the recorded revision against admitted feedback and navigation setpoints. The wire must carry every expected command field at the unique tick and sequence, including exact axis, mode, flags and target. The cell uses a durable world prefix, a verified retained bundle, replay of both controllers and the original interlock state. Live and cold reports use these records. A missing interval gives an incomplete drive result and unavailable affected metrics. A freshly reopened worker-loss/lost-ACK run uses a private copy, avoiding subsequent restart annotations in the original report checkpoint. Historical unknown-ACK checkpoints which had already been reopened are interpreted at their recorded report horizon.

RED on the initial verifier exposed latency false completion, independently changed axis/mode/sequence/tick/target, missing repeats, and forged cell event/outcome (9 failed, 1 positive control passed). The archived edit simultaneously changed latency status, served and attention and duplicated one wheel, with a resealed file inventory; the original verifier still gave 1/1. The earlier cell-completeness mutation was already detected indirectly via metric completeness. The current tests demand exact world-derived complete/issues/events and cold disk corruption handling. Logs `/tmp/v07-3-verifier-red.log`, `/tmp/v07-3-archived-red.log`. Another isolated regression supplied scene wheel limits narrower than the drive's own; the previous output reached 2.22222 rad/s against 2.0. The complete controller suite on the fix passed 31/31, covering acceleration, jerk, arrival, reversal, small step, slowdown, zero dt, fault, stop/release, legacy controller vectors and tighter admitted wheel limits (`/tmp/v07-3-wheel-bound-red.log`, `/tmp/v07-3-allctrl.log`).
