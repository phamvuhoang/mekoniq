# Kiểm tay trình duyệt — not_run

Chrome, Firefox và Safari: `not_run`. Chưa có thao tác kiểm tay và ảnh hộp hỏi quyền truy cập mạng cục bộ trên build HTTPS của bản pin này. Firefox chưa được cài trong môi trường ghi; công cụ hiện có không điều khiển trực tiếp giao diện và hộp quyền của ba trình duyệt. Các suite Playwright trong qualification là bằng chứng tự động riêng, không được đổi nhãn thành kiểm tay. Theo spec §6.4, nhóm kiểm tay này không thuộc gate.
