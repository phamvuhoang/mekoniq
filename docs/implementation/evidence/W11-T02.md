## Limits (why blocked_external — all stated in the artifacts' `claim` / `unmeasured`)

- In-process: no tablet model, radio, WebSocket, Android battery/thermal/storage, no robot mission traffic (robots are only seeded). The "kitchen delivery" figure is commit + read in the same process, not LAN delivery.
- The simulated days use a moved clock; that is not a soak. 24 h soak and spike runs were not done.
- Hosted Free numbers (database baseline, Storage, real egress, Realtime messages, cached egress, MAU) are unmeasured (`null`); local resources are not evidence of a hosted project, and a hosted run must never ping around a pause.
- Egress and Realtime figures are models (stated formulas), not provider counters. The full module set and `trial-service` share one build (verified elsewhere); this run used the full set only.
- Storage and Realtime provider outages were exercised only as far as the cloud-unavailable test; Storage failure paths remain covered by `storage-failure.test.ts`.
