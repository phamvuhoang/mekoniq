Conditions:

Test held world tick pause/cancel, late step settlement, expired/transferred writer, cached action identity and public close/reclaim ordering. Do not silently change unrelated legacy mock/navigation semantics just because the shared Run class hosts several modes.

Handle its late-arrival/fallback and returned authoritative revisions explicitly; do not silently retry an ambiguous mutation under a different payload/action identity. Preserve failed/unknown semantics and current once-only/idempotent receipts.

The capture reader previously equated every tick delta with requested ticks; a valid final curtailed batch must instead carry/derive an exact actual committed prefix correlated to the same final control/horizon. Require every actual worker tick exactly once and preserve no-gap/identity/time checks. Do not turn this into acceptance of arbitrary shorter, missing or unrelated worker streams.
