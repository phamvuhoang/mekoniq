### Changes and self-review

`world-evidence.ts` captures the pre-attempt append horizon before validation/WAL/automatic flush can advance its local observation. Internal failures are provisional: the first Source-owned `fail()` may replace that local boundary and reason with its authoritative logical commit/ACK horizon. Once Source-owned, subsequent local failure/finish cannot move it. The runner continues to own its unchanged ACK/pending/commit ordering and terminal latch; no runtime runner change was needed.

After writing a chunk, the recorder transfers its rows into the next manifest's ownership and retires those rows/counts from memory before fallible manifest publication, WAL clearing or intent unlink. Failure recovery/finish can persist that same manifest, but cannot reflush the owned rows into a duplicate/reversed range. A cleanup failure remains incomplete/unpublished; its original hashed prefix stays readable. Before chunk publication, still-buffered validated records may be published during terminal finish as evidence of the observed ACK, without claiming logical commit or completion.

Meaningful regressions use actual recorder filesystem operations, injecting only the named durable-write/unlink boundary. Unit cases cover automatic chunk-write failure, post-publication WAL clearing, intent unlink, and manifest-publication failure; assertions include pre-attempt and Source-owned horizons, immutable published bytes/ranges, terminal append refusal and readable incomplete prefix. Real Source runner tests connect the actual recorder to the existing world seam and assert checkpoint tick0, old public pose/stale state, snapshot tick0, pending tick1/ACK1/exact command at `acked`, manifest `{targetTick:1,lastCommittedTick:0,ackTick:1}`, no logical commit, exactly one physical-step call, no retry and no respawn after reopen. The worker/physics itself is deliberately a controlled seam double in these error-path tests; physical evidence remains the retained native campaign.

Self-review found no physical/compiler/controller/schema/legacy-recorder changes. Runtime diff is solely the world recorder; tests and separately named R1 audit/hash files make up the remainder.
